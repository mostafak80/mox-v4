# MOX-V2 Clean

## الملفات
- `index.html`
- `style.css`
- `app.js`
- `manifest.webmanifest`
- `sw.js`
- `firestore.rules`
- استخدم نفس الملف الموجود عندك: `assets/logo.png`

## التثبيت
استبدل `index.html`, `style.css`, `app.js` في المستودع بهذه النسخة وأضف الملفات الجديدة. لا تحذف `assets/logo.png` الحالي.

## ترحيل البيانات
أول تشغيل على نفس الدومين/المتصفح يقرأ مفاتيح MOX القديمة من `localStorage` وينقل العمليات والعروض والمصاريف تلقائيًا إلى IndexedDB. البيانات القديمة لا يتم حذفها أثناء الترحيل.

## Firebase الآمن
1. من Firebase Console فعّل Authentication > Email/Password.
2. من Firestore Rules الصق محتوى `firestore.rules` وانشره.
3. افتح MOX-V2 > الإعدادات > المزامنة.
4. الصق Firebase config بصيغة JSON.
5. أنشئ حسابًا أو سجّل الدخول بنفس البريد وكلمة المرور على الكمبيوتر والموبايل.
6. البيانات ستصبح داخل `users/{uid}/apps/mox-v2` ولا يستطيع مستخدم آخر الوصول إليها مع القواعد المرفقة.

## ملاحظات
- لا يوجد Sync Code ثابت داخل الكود.
- Password المحلي مخزن كـ PBKDF2-SHA256 hash وليس Base64.
- النسخ الاحتياطية التلقائية لا تحتوي نسخًا داخل نسخ، ويتم الاحتفاظ بآخر 5 Safety Snapshots فقط.
- تصدير Excel يستخدم 8 أعمدة فقط بنفس المواصفات المطلوبة، والتاريخ نص `1/5`, `2/5`... والأرقام إنجليزية.
