# MOX-V4 — Store Finance OS (Cloud-Synced & Multi-User)

نظام إدارة العمليات المالية والمصاريف والأرباح للمتاجر الإلكترونية، مع مزامنة سحابية لحظية عبر Firebase ودخول بحساب Google.

---

## الجديد في MOX-V4

1. **تسجيل الدخول بحساب Google (Firebase Authentication)**
   - تسجيل دخول آمن عبر Google Sign-In (مع دعم الـ Popup على أجهزة الكمبيوتر وRedirect للموبايل وSafari وPWA).
   - شاشة تسجيل دخول مخصصة بتصميم Glassmorphism أنيق.
   - معلومات المستخدم (الصورة، الاسم، البريد) في القائمة الجانبية وزر خروج آمن.

2. **عزل كامل للبيانات وتعدد المستخدمين (Multi-User Data Isolation)**
   - كل مستخدم له قاعدة بيانات IndexedDB محلية مستقلة تمامًا: `mox-v4-${user.uid}`.
   - عند تسجيل الخروج يتم تفريغ الذاكرة فورًا ومنع أي تسريب للبيانات لمستخدم آخر.
   - كل مستخدم له مسار خاص ومحمي في Firestore: `users/{uid}/...`.

3. **مزامنة سحابية لحظية (Real-Time Cloud Sync)**
   - مزامنة لحظية بين الهاتف والكمبيوتر فور حفظ أي عملية أو تعديل عرض أو تسجيل مصروف.
   - مؤشر حالة المزامنة في الشريط العلوي (🟢 متصل — تمت المزامنة / 🔄 جارٍ المزامنة / 🟠 تغييرات بالانتظار / 🔴 بدون إنترنت).
   - تبويب "الحساب والمزامنة" في شاشة الإعدادات لعرض حالة الحساب وزر "مزامنة الآن".

4. **العمل بدون إنترنت وحماية البيانات (Offline First & Safety Snapshots)**
   - التطبيق يعمل بالكامل دون اتصال بالإنترنت، ويحفظ التغييرات محليًا ويرفعها تلقائيًا عند عودة الاتصال.
   - أخذ Safety Snapshot تلقائي محليًا قبل أي تعديل أو استرجاع أو حذف أو ترحيل.

5. **ترحيل تلقائي وسلس لبيانات MOX السابقة (Seamless Migration)**
   - التطبيق يكتشف تلقائيًا وجود بيانات سابقة على الجهاز من نسخ `mox-v2-db` أو `mox-v4-db` أو `localStorage`.
   - عند أول تسجيل دخول بحساب Google، يظهر مربع حوار يوضح عدد العمليات والعروض بدقة ويسأل المستخدم عن رغبته في رفعها لحسابه السحابي مع الاحتفاظ بالنسخة المحلية للأمان.

6. **مراجعة وتصنيف رسائل المحفظة (Unclassified Transactions Queue)**
   - حفظ كافة الإيصالات الواردة حتى لو لم تطابق عرضًا مسجلًا مسبقًا، مع وضعها في قسم "معاملات تحتاج مراجعة" على لوحة التحكم وشارة تنبيه بالعدد، مع اقتراحات ذكية بنسب الثقة من MOX Smart.

## بنية الملفات

- `index.html`: هيكل الواجهة ولوحة التحكم بأسلوب Module.
- `style.css`: التصميم وأنماط الشاشات والحركات ومؤشرات المزامنة وتسجيل الدخول.
- `app.js`: المحرك الأساسي للتطبيق والمنطق التجاري وإدارة الحالة.
- `auth.js`: وحدة المصادقة وإدارة جلسة Google Sign-In وشاشة الدخول.
- `cloud-sync.js`: وحدة المزامنة مع Firestore، دمج البيانات، ومراقبة حالة الشبكة.
- `migration.js`: وحدة ترحيل البيانات المحلية إلى السحابة مع شريط التقدم.
- `firebase.js`: تهيئة SDK الخاص بـ Firebase (Auth & Firestore) مع دعم التخزين المؤقت دون اتصال.
- `firebase-config.js`: بيانات الاتصال بمشروع Firebase.
- `firestore.rules`: قواعد الأمان السحابية لـ Cloud Firestore.
- `sw.js`: Service Worker لدعم الـ PWA والتخزين المحلي دون اعتراض طلبات المصادقة.
- `manifest.webmanifest`: تعريف التطبيق كـ PWA قابل للتثبيت.

## خطوات التفعيل في Firebase Console

تم ربط بيانات مشروعك تلقائيًا في `firebase-config.js`:
- **Project ID**: `mox-v2-22fcc`

للتأكد من جاهزية المشروع، تأكد من الخطوتين التاليتين في [Firebase Console](https://console.firebase.google.com):

### 1. تفعيل Google Sign-In
1. ادخل على مشروع `mox-v2-22fcc` > **Build** > **Authentication**.
2. في تبويب **Sign-in method**، اضغط على **Google** وفعّل الخيار (Enable).
3. اختر بريد الدعم واضغط **Save**.
4. في تبويب **Settings** > **Authorized domains**، تأكد من إضافة النطاق الذي يعمل عليه موقعك (مثل `localhost` أثناء التجربة المحلية، أو نطاق موقعك المستضاف).

### 2. تفعيل Firestore Database وقواعد الأمان
1. ادخل على **Build** > **Firestore Database**.
2. إذا لم تكن منشأة، اضغط **Create database** واختر أقرب منطقة جغرافية.
3. ادخل على تبويب **Rules**، وضع القواعد التالية ثم اضغط **Publish**:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

## التشغيل المحلي

نظرًا لأن التطبيق مبني بنظام ES Modules الحديثة ويستورد مكتبات Firebase عبر ESM:
- يجب تشغيله عبر سيرفر محلي (Local HTTP Server) وليس بفتح ملف HTML مباشرة (`file://`).
- يمكنك استخدام:
  - **VS Code Live Server**: كليك يمين على `index.html` ثم `Open with Live Server`.
  - أو أمر Node: `npx serve .`
  - أو بايثون: `python -m http.server 8000`
